复购分析 测试版

测试版 · 只读：这个页面不会修改任何订单、会员、库存；导入的文件只在这个浏览器里计算，不会上传。手动填的原因只存在这台电脑的浏览器里。

选择要看的数据

三种方式都只读。先用「假数据」看看效果，再导入真实订单。

假数据

约 150 位虚构顾客：规律复购的、停买的、只买一次的、从没成交的。不接任何服务器。

导入订单文件

选择从后台或 Supabase 导出的 JSON 或 CSV 文件，可以一次选多个（订单 + 会员 + 缺货）。

怎么导出真实订单？
  1. 正式后台同一个浏览器里，打开
    /.netlify/functions/get-orders?password=后台密码&status=all
    页面显示一大段文字，按 Ctrl/⌘+S 存成 orders.json。
  2. （可选，会员合并更准）打开 /api/admin/members?password=后台密码，存成 members.json。
  3. （可选，缺货原因）打开 /api/stock，存成 stock.json。
  4. 回到这里点「选择文件」，三个一起选上。

也可以用 Supabase → Table Editor → orders → Export → CSV。只读，不会改数据。

在线读取（只读）

页面部署在网站上（本地测试服务器或 Netlify 预览）时，用后台密码直接读订单。只发读取请求。
